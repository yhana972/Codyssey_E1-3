# Mini NPU Simulator

## 프로젝트 소개

Mini NPU Simulator는 AI 및 NPU에서 사용되는 핵심 연산 중 하나인 MAC(Multiply-Accumulate) 연산을 Pure Python으로 구현하는 프로젝트입니다.

입력 패턴과 두 개의 필터를 같은 위치끼리 곱한 뒤 결과를 모두 더하여 MAC 점수를 계산하고, 두 점수를 비교하여 입력 패턴이 어느 필터와 더 유사한지 판정합니다.

외부 라이브러리는 사용하지 않고 Python의 기본 문법과 표준 기능만 사용합니다.

## 실행 방법

```bash
python main.py
```

프로그램 실행 후 메뉴에서 사용할 모드를 선택합니다.

```text
=== NPU 시뮬레이션 ===
1. 사용자 입력 (3X3)
2. data.json 분석
0. 종료
```

현재 1단계에서는 `1. 사용자 입력 (3X3)` 모드를 구현했습니다.

## 현재 구현 기능

* 3×3 필터 A 입력
* 3×3 필터 B 입력
* 3×3 패턴 입력
* 입력값의 행/열 개수 검증
* 숫자가 아닌 값 입력 시 예외 처리
* N×N 배열 유효성 검사
* 패턴과 필터의 크기 비교
* 반복문 기반 MAC 연산
* A/B 점수 비교
* epsilon 기반 동점 판정
* 메뉴 반복 실행 및 프로그램 종료

## MAC 연산

MAC은 Multiply-Accumulate의 약자로, 같은 위치의 값을 곱한 후 결과를 계속 누적하여 더하는 연산입니다.

예를 들어 3×3 배열을 비교할 경우 총 9개의 위치를 순회합니다.

```text
pattern[row][col] × filter[row][col]
```

각 위치의 곱셈 결과를 `score`에 누적하여 최종 MAC 점수를 계산합니다.

3×3에만 고정되지 않도록 배열의 크기를 `len(pattern)`으로 구하고 반복문의 범위로 사용했습니다.

따라서 정상적인 N×N 배열이라면 동일한 MAC 함수를 5×5, 13×13, 25×25 데이터에도 재사용할 수 있습니다.

## 입력 검증

사용자가 입력한 각 행은 공백을 기준으로 분리합니다.

예를 들어:

```text
0 1 0
```

은 다음과 같은 값으로 변환됩니다.

```text
["0", "1", "0"]
```

각 값은 `float`로 변환하여 MAC 연산에 사용할 수 있도록 저장합니다.

입력한 숫자의 개수가 요구되는 크기와 다르면 해당 행을 저장하지 않고 다시 입력받습니다.

숫자로 변환할 수 없는 값이 포함된 경우 `ValueError`를 처리하여 프로그램이 종료되지 않고 재입력하도록 구현했습니다.

## 배열 검증

MAC 연산은 같은 위치의 값끼리 곱하기 때문에 패턴과 필터가 정상적인 N×N 배열이어야 합니다.

`validate_matrix()` 함수에서는 다음 조건을 검사합니다.

* 빈 배열이 아닌지 확인
* 각 행의 열 개수가 전체 행 개수와 동일한지 확인

또한 `validate_same_size()`를 사용하여 패턴과 필터의 크기가 동일한지 확인할 수 있도록 구성했습니다.

## 점수 비교 정책

실수는 컴퓨터 내부에서 부동소수점 방식으로 저장되기 때문에 계산 결과에 매우 작은 오차가 발생할 수 있습니다.

따라서 두 점수를 `==`로 직접 비교하지 않고 다음 조건을 사용합니다.

```python
abs(score_a - score_b) < 1e-9
```

두 점수의 차이가 `0.000000001`보다 작으면 부동소수점 연산 과정에서 발생할 수 있는 미세한 차이라고 판단하여 동점으로 처리합니다.

판정 규칙은 다음과 같습니다.

```text
점수 차이 < 1e-9 → UNDECIDED
A 점수 > B 점수  → A
B 점수 > A 점수  → B
```

## 1단계 테스트 결과

정상적인 Cross 필터와 X 필터를 입력하고 X 패턴을 입력했을 때 다음 결과를 확인했습니다.

```text
A 점수 : 1.0
B 점수 : 5.0
판정 : B
```

또한 다음 오류 입력을 테스트했습니다.

* 한 행에 필요한 숫자 개수보다 적게 입력
* 한 행에 필요한 숫자 개수보다 많이 입력
* 숫자가 아닌 문자열 입력
* 메뉴에서 지원하지 않는 번호 입력

잘못된 입력이 발생해도 프로그램이 비정상 종료되지 않고 재입력 또는 메뉴 재선택이 가능하도록 구현했습니다.
